全新开发的 Windows 磁盘清理工具（非任何第三方软件的修改版）。默认将文件送入系统回收站（可还原），不会不可逆删除；程序默认以管理员身份运行。
界面采用左侧导航 + 卡片式主区设计：**常规清理 / 微信专清 / 企业微信专清 / WPS缓存专清 / 扫描大文件 / 日志**（已移除「关于 / 反馈」入口及其分隔线；全盘扫描整合在「常规清理」内）。各扫描入口范围独立、互不干扰。

## 功能

1. **常规清理**：逐项列出 C 盘 12 类可清理项 —— 临时文件和日志文件、设备驱动程序文件、预读取文件(Prefetch)、缩略图缓存、图标缓存、系统临时文件（`C:\Windows\Temp`）、Windows 更新缓存（`C:\Windows\SoftwareDistribution\Download`）、Windows.old 残留目录（`C:\Windows.old`）、DirectX 着色器缓存、用户临时文件（`C:\Users\<用户名>\AppData\Local\Temp`）、浏览器缓存（Chrome / Edge）、系统错误报告（WER）。**只列出扫描到内容的类别**；表格逐行标注**风险等级**（低/中/高风险文字分别显示为绿/黄/红）与**删除后果**短句，点击任一项在右侧详情面板查看完整删除后果、建议与真实路径。驱动仓库 `C:\Windows\System32\DriverStore\FileRepository` 含当前设备正在使用的驱动，标为高风险且**只统计占用、不参与清理**（无法勾选）；Windows.old 为高风险、默认不勾选，删除后无法回退旧系统。目录类只清内容、保留目录本身，清理项一律送入系统回收站、可随时还原。
2. **微信专清**：遍历**所有本地固定磁盘**定位 `WeChat Files` / `xwechat_files`，按 **7 类**展示：图片、视频、音频、文件、**文档**、缓存、聊天记录（只统计不清理）。v1.7.0 新增「文档」类别，按扩展名优先汇总 Word / Excel / PPT / PDF / WPS / CSV 等常用办公文档，**与「文件」严格互斥、不重复统计**；「文件」「文档」均按精确文件路径清理，勾选其中一类不会连带删除另一类。结果在「路径 / 说明」列标注覆盖的数据目录数量与盘符，详情面板「位置」逐条列出全部数据目录且**可点击直接打开**，日志同样完整记录；不可访问磁盘与无权限目录自动跳过并在日志提示。
3. **企业微信专清**：遍历**所有本地固定磁盘**定位 `WXWork`，类别与微信一致（图片/视频/音频/文件/文档/缓存/聊天记录，共 7 类）；同样列出全部数据目录并支持点击打开、跳过不可访问/无权限位置。
4. **WPS缓存专清**：
   - 枚举 Kingsoft 全部缓存目录并按占用空间排序；
   - 重点标注并默认勾选 `office6\backup`（本地自动备份）与 `WPS Cloud Files`（云同步缓存）；
   - 覆盖缓存、日志、崩溃报告等其他目录；
   - 清理时若检测到 Word/表格/演示/PDF 等文档，弹窗选择：转存到默认目录 `D:\wps转存`（推荐，按原目录结构移动，目录不存在自动创建）/ 转存到其他位置… / 直接清理 / 取消；
   - 可按 全部 / 30天 / 90天 / 180天前 过滤清理范围；
   - 详情面板附长期方案提示（将 WPS 备份中心目录改到 D 盘）；
   - 支持 `/scan` 纯扫描模式，只出报告不动任何文件。
5. **扫描大文件**：扫描范围与文件大小均为**下拉菜单**；范围下拉显示各盘可用空间并含「全部磁盘」，大小阈值固定 6 档（100M以上 / 200M以上 / 500M以上 / 1G以上 / 2G以上 / 4G以上，默认 4G以上）。头部按钮组与其他模块完全一致（取消全选 / 全选 / 清理选中项 / 一键扫描），筛选栏只保留两个下拉；结果可清理（双击打开所在目录）。

## 扫描交互（新增）

- 任意入口开始扫描时弹出**扫描进度窗**：环形加载动画、主状态（如「正在扫描 C 盘」）、动态子状态（如「正在统计：用户临时文件」）、进度条与 `i / total` 计数；点「取消扫描」可随时中断。扫描完成自动关闭。

## 清理交互（已修复并增强）

- 在任意结果表格的「选择」列点击即可勾选/取消，或用「全选 / 取消全选」。
- 点击「清理选中项」后弹出**实时进度小窗**：逐文件显示正在删除的文件名、进度条、`已完成/总数` 与 `成功/失败` 计数；可随时「停止清理」。
- 删除完成后小窗自动关闭，**立即重新扫描并刷新当前列表**，同时更新磁盘使用量。
- 所有删除均通过 `SHFileOperationW(FO_DELETE | FOF_ALLOWUNDO)` 送入系统回收站，可还原。

## 使用

- 双击 exe（UAC 提示确认）以管理员身份运行。左侧导航切换功能页。
- 每个页面：扫描 → 勾选项目 → 清理选中项（送回收站）；右侧显示项目详情、删除后果与路径。**详情面板「位置」下的目录均为可点击链接**，点击直接在资源管理器中打开对应本地文件夹（指向文件时打开其所在文件夹）；若目录不存在、已被清理或无权限访问，会弹出明确提示。
- 纯扫描模式（不修改任何文件）：
  ```
  DiskCleaner.exe /scan
  ```
  扫描结果写入当前目录下的 `DiskCleaner_扫描报告_<时间戳>.txt`（报告含版权信息）。
- 侧边栏展示本机全部固定磁盘的实时容量状态（可滚动），并保留开发者版权信息。
- 日志页：可复制全部、打开日志目录、清空显示。

## 技术

- Python 3.8 + tkinter；PyInstaller `--onefile --windowed --uac-admin` 打包，图标 `icon.png` → `app.ico`；侧边栏图案使用 `logo_small.png`（与软件 icon 同源）。
- **回收站删除关键修复**：`SHFILEOPSTRUCTW.pFrom` 是双 NUL 结尾宽字符串，Python 3 的 `c_wchar_p` 字段赋值会因内嵌 NUL 抛 `ValueError: embedded null character`，导致清理静默失败。现改用 `create_unicode_buffer` 保留内嵌 NUL 并以指针赋值，清理正常生效。
- 源码位于 `src/`：
  - `core.py`：磁盘枚举、体积统计、回收站删除（含进度/取消回调）、时间过滤、目录结构转存
  - `wechat.py`：微信 / 企业微信扫描（跨所有本地磁盘查找数据目录，7 类聚合含「文档」）
  - `wps.py`：WPS 缓存扫描
  - `disktools.py`：全盘垃圾 / 大文件扫描
  - `ui.py`：主题配色、侧边栏（磁盘状态区可滚动）与卡片组件
  - `app.py`：GUI、实时删除进度窗与 `/scan` 入口

## 重新构建

```
"C:/Program Files (x86)/Python38-32/python.exe" -m PyInstaller --noconfirm --onefile --windowed --clean \
  --uac-admin --name DiskCleaner --icon app.ico \
  --add-data "app.ico;." --add-data "logo_small.png;." app.py
```

（需在 `src/` 目录下执行；Python 3.13 内置环境缺少 tkinter，请使用带 tkinter 的 Python 3.8。`--uac-admin` 使 exe 默认请求管理员权限。）
